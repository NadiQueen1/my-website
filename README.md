# My Website

A responsive beginner-friendly website built with HTML, CSS, and JavaScript.  
It features a modern landing page design, clean layout, interactive buttons, and responsive styling for different screen sizes.

## Features

- Modern hero section
- Navigation bar
- Responsive design
- Interactive buttons using JavaScript
- Clean card section
- Soft background colors and shapes

## Technologies Used

- HTML
- CSS
- JavaScript

## Project Purpose

This project was created to practice basic frontend web development skills and learn how to build a simple modern website from scratch.
